# chordpro-samples fixtures

Copied verbatim from [chordprosite](https://github.com/ptsefton/chordprosite)'s
`samples/` folder (same author, Peter Sefton, as this repo) for use as realistic
`chordpro-input` plugin test fixtures — see `src/plugins/chordpro-input/SPEC.md`.

Not copied: `sample.setlist.html` and `makefile`, which are chordprosite build
artifacts with no relevance here.

Note: chordprosite itself is licensed GPL-3.0, while this repo is Apache-2.0. The
copied files are song charts and a setlist written by this repo's own author, not
third-party GPL code, so relicensing them for use here is the author's call — flagged
here for visibility rather than left unstated.
